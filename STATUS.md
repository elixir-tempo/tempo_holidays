# Status

**Status:** active, 2026-11-01

0.3.0 is the current release (2026-11-01): Bangladesh's national days written in the Bengali calendar are read, through Calendrical's Bangla calendar, so every rule of the dataset is now read. 0.2.0 gave holiday names in the request's locale, a Gettext catalog of them, and `day_start/1`. Public holidays as Tempo recurrences for any window, the [date-holidays](https://github.com/commenthol/date-holidays) dataset's rules read by `Tempo.DateRule`. Functional work is tracked in `TODO.md` and designed in `plans/`.

It takes Tempo 2.3, Calendrical 2.4, Localize 1.5 and Astro 2.11 from hex.
